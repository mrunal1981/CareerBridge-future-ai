# CareerBridge frontend

## Build
- Replace the placeholder with a polished CareerBridge landing page and dashboard experience.
- Add a state-based light/dark theme toggle with the supplied palettes and smooth transitions.
- Build four interactive agent views using mock data: resume review, counseling, scholarships, and jobs.
- Add animated page/tab transitions, scroll reveals, counters, progress indicators, and responsive mobile navigation.

## Visual direction
- Use a bright editorial product style with indigo/violet structure, amber highlights, subtle glass surfaces, and restrained ambient gradients.
- Keep layouts clear and student-friendly, with large touch targets and strong contrast in both themes.

## Technical details
- Use the existing TanStack React app, Tailwind design tokens, Lucide icons, and Framer Motion.
- Keep everything frontend-only; no accounts, uploads, or records will be persisted.
- Add unique metadata for the home experience and verify the live page at desktop and mobile widths.
